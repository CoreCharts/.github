# CoreCharts

CoreCharts is a Bitcoin-only on-chain analytics platform focused on transparent methodology, connected metrics, and research-grade charting.

The platform is built around a simple principle: Bitcoin on-chain data should be verifiable. CoreCharts connects each chart to the definitions and methodology needed to understand how the metric is constructed and where its limits are.

## Focus

CoreCharts focuses on Bitcoin on-chain research, including address activity, valuation metrics, supply dynamics, mining economics, UTXO and coin age data, realized cap families, SOPR, NVT, MVRV, and related cycle-regime indicators.

## About

CoreCharts is Bitcoin-only by design. The goal is not to cover every asset, but to study one monetary network with consistent definitions, transparent methodology, and a clean research environment.
